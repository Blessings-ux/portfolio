Paper Duet

Personal project · Solo build

Paper Duet is a full-stack document utility that merges multiple file types — images, Word documents, and more — into a single combined PDF, built with a decoupled front end and back end and user authentication.

  • Built the front end in HTML/CSS/JS and a separate Node.js backend service to handle merge logic
  • Implemented user authentication with Supabase, including custom SMTP configuration for reliable email delivery
  • Supports mixed input types (images, Word docs, and other formats) in one merge flow, outputting a single clean PDF
  • Deployed frontend on Netlify, backend on Render
